# Aragón en línea

Plataforma web del Conjunto Residencial Aragón (Neiva, Huila). Sitio público: https://aragonenlinea.github.io

- **Publicar contenido** (comunicados, documentos, eventos, contactos): `docs/manual-administracion.md`
- **Cómo está hecho y cómo continuarlo:** `docs/guia-tecnica.md`
- **Reglas y fases del proyecto:** `CLAUDE.md`

El contenido del sitio está en `web/datos/`. Cada cambio guardado en la rama `main` se publica solo en 1 o 2 minutos.

Este repositorio es público: no suba datos personales de residentes, documentos sin revisar ni claves.
